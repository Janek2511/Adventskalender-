# 🎄 Klassen-Adventskalender 2026

Willkommen bei unserem gemeinsamen Adventskalender!

Dieser Adventskalender begleitet unsere Klasse durch die Weihnachtszeit.

## ✨ Das erwartet euch

- 24 weihnachtliche Türchen
- Jeden Tag wird ein neues Türchen freigeschaltet.
- Hinter jedem Türchen verstecken sich:
  - Ein interessanter Weihnachtsfakt
  - Ein positiver Spruch
  - Eine freundliche Tagesaufgabe
- An ausgewählten Tagen gibt es zusätzlich einen Weihnachtswitz.
- Besondere Überraschungen zu Nikolaus, den Adventssonntagen und Heiligabend.

## 📅 Start

Der Adventskalender startet am 1. Dezember 2026.

## 🎅 Viel Spaß!

Ich wünsche euch eine schöne Adventszeit und frohe Weihnachten!
